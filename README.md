# Juragan Paket Data Website

Website toko paket data XL untuk seluruh Indonesia:
- AKRAB XLA  
- AKRAB XDA  
- CIRCLE XCLP  
- Masa Aktif  

## Cara pakai
- Buka `index.html` di browser (misalnya: Chrome, Firefox).  
- Pilih layanan → pilih sub layanan → klik tombol **Pesan ke WA**.  
- Pesan otomatis terbuka di WhatsApp ke admin: `6287786803835`.  
- Pembayaran via QRIS, kirim bukti pembayaran ke WhatsApp.
